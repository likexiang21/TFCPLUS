# 290 作物流程定制与产量平衡计划（对 289 的修订）
> 日期：2026-10-28
> 性质：**计划**，不是实现。
> 针对 289 的不足：289 的流程按族套模板；本计划为每一种作物指定**流程 profile + 产量目标 + 平衡规则**。
> 依据：`117 §6.8`、`126 §12.11/§12.12`、`289`。

## 1. 产量基线（实测）
当前 A 与 TFC 的普通作物掉落表几乎完全一致：
- 主产品：`tfc:crop_yield_uniform`，`min=0`，`max=uniform(6,10)`；- 种子：通常 1 个，部分作物 1–2 个；- 红/黄甜椒：两组 `min=1`、`max=uniform(4,5)`；- melon/pumpkin：不走作物 age 掉落，走果实方块掉落；- 当前所有普通作物**没有按物种区分产率**，这正是需要平衡的地方。
因此本计划原则：
1. **不先大改原始掉落**（尤其 TFC，避免存档/兼容冲击）；2. 先用**加工转化率、副产物比例、种子返还**做平衡；3. 原始掉落确实需要改时，只改 B 自有 A 作物，并保留旧值作为回滚基线。

## 2. 平衡公式与验收带
对每次收获定义：
```text
raw        = 主产品原始产量（单位）
seedBack   = 返还种子/种薯数
processed  = 初加工后主产品单位
byproduct  = 副产品单位

约束 1：seedBack >= 1（种子作物；无性繁殖按 1 个种薯/段计）
约束 2：processed <= raw（主产品加工不凭空增加；副产品来自秸秆/皮/荚等非主产部位）
约束 3：processed >= 1（每个作物必须有可用的初加工主产物）
约束 4：byproduct >= 1（每个作物必须有副产品出口）
```
平衡原则：
- **高营养密度/高价值**（油料、豆类、香料）→ processed 单位低、副产物价值高；
- **高水量/低密度**（叶菜、根菜）→ 鲜重 raw 高、干重 processed 低；
- **纤维/油料双主产** → 纤维与油各自有独立产量，不可互相替代；
- **TFC 原版不降低 raw 产量**；B 只调整加工转化率与副产物；
- 所有产量目标以 20 次收获的均值/区间验收，不用单次极值。

## 6. 每作物验收
每个作物必须通过：
1. `raw` 落在该行目标带；
2. `seedBack >= 1`（或等价的种薯/种茎）；
3. `processed >= 1` 且 `processed + byproduct <= raw`；
4. 副产品有至少一个真实出口；
5. 20 次收获均值/区间在带内；
6. 与相邻同类作物相比，单位营养/价值不出现数量级失衡。

## 7. 未决问题
1. 是否允许修改 A 的原始掉落表；TFC 29 的 raw 掉落建议不动。

3. 油料/纤维双主产的产率如何分账（纤维与油是否共用同一 raw）。
4. 种子返还：种子 1 个是否够维持扩张，还是需要 1–2 个保底。
5. TFC 29 资源覆盖与 B 生产/培育链的行为层如何合并。
