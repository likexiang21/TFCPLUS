## 三、技术发现全表（每条都有实测证据）

### 3.1 渲染器（此前完全不可信）
1. **逐像素 z-buffer 深度测试符号反了**：`zd = y*sin(pitch) + zr*cos(pitch)` 中 **zd 越大越靠近相机**，
   而代码写的是 `if (dz > 1e-9) continue;` ⇒ **更近的面整片被拒** ⇒ 屏幕上只剩最先画的一片。
   修正：`if (dz < -1e-9) continue;` + 共面时用面序号决胜。
2. **`zbuf` 初值必须是 `double.MinValue`**。用 `MaxValue` 时第一片面的 `dz` 是极大负数、被判"更远"丢弃 ⇒ 整幅空白。
3. **shade 计算写在写 `data` 之后** ⇒ 写进去的永远是旧值 ⇒ **从未生效**（实测渲染色 = 贴图原色）。
   同时补上 MC 语义：element 的 `"shade": false` = 不接收方向光。
4. **`up`/`down` 共面偏置方向反了**（水平板从上方看到的应是 `up` 面）。

### 3.2 `minecraft:block/crop` 模型：`.probe` 里那份是**伪造**的
- 伪造版 = **2 片 ±45° 板**。**数学上必然自重合**：沿 x 的板转 −45° 与沿 z 的板转 +45°，
  方向都变成 (0.707, 0.707)（Δθ=90° 让初始垂直的两片变成平行）⇒ **无论怎么修渲染器都画不出十字**。
  ⇒ 这就是用户"十字根本没被渲染出来""压根就没有什么十字"的**根因**。
- **真品在客户端 jar** 的 `assets/minecraft/models/block/crop.json`：
  **4 片互相平行的竖直板、无 rotation、两对各错开 4 格、全部 `"shade": false`、高度 −1…15**。

### 3.3 ⚠️ 计数器不可信
`faces=N/M` 里的 `drawn++` **写在面循环末尾、无条件自增** —— 画没画上都报正常值。
**别再拿它当"画上了"的证据。**

### 3.4 贴图命名错位（影响 69 个物种）
- 被模型引用的贴图名 **765** 个，实际文件 **1410** 张 ⇒ **死贴图 658 张**
- 其中形如 `X_N` 且存在对应 `X_age_N` 的：**385 张 / 69 个物种**
- 活版 `X_age_N` **全部是 09-26 14:37 同一时刻生成的**（一个批量脚本把此前手绘成果整个绕过去了）
- 铁证：把 TFC `lentil_5` 与我方 `fenugreek_age_5` dump 成网格 ⇒ **16 行完全相同、色数相同、每色用量相同**，
  只有 RGB 被整体调过 ⇒ **它就是兵豆贴图的换色拷贝**

### 3.5 TFC 画法读数（学审美的材料，详见 `docs/96`）
- `lentil_0`：**16 px / 5 色 / 全在 y9~y15 / 上半 9 行全空 / 零散 1px 点**
- `lentil_5`：110 px / 9 色 / **7 种极相近的暗橄榄绿 + 唯一亮黄绿高光 RGB(190,207,98)（散布在各行）** /
  逐行全是断开的 1~2px 短段
- **TFC 靠"密度 · 分布范围 · 横向宽度 · 色阶数 · 色相 · 底部特征"区分同族物种**，从不改变语法
- **形态族画法**：禾本科=竖直细秆丛+成熟转金黄+顶穗 · 根茎类=上部叶冠+成熟期才冒彩色根块 ·
  果菜类=叶丛+白花(age4)+红/黄大果(age5+) · 叶菜=逐龄滚成叶球 · 匍匐类=横向铺地 ·
  开花作物=整株撒满彩色小花 · 攀援类=独立棕色支柱（`_stick`，从苗期就有）
- **枯死** = 整株换枯色、形态保留，**但收获器官必须留下**（根茎类露根、果菜类挂果）
- **野生态 ≈ 成熟态带标志器官**
- **双段作物（`_top`/`_bottom`）必须拼成整株来看/来画/来验收**；接缝对齐只是最低要求
- ⚠️ **"密而透"的实质是色阶逐像素打散，不是往实心块上戳几个洞**
  （TFC 甜椒每行也有 12px 连续段，但用了 24~30 档极相近的绿）

## 六、工具与命令速查

```powershell
$v = 'D:/111/最强服务器/.minecraft/versions/Essential TerraFirmaCraft (TFC)'

# 设计稿 -> PNG（自包含调色板 key=RRGGBB + 恰好 16 行 x 16 字符，'.'=透明）
& "$v/.probe/texture-design/draw2.ps1" -Design "$v/.probe/texture-design/px/chili_work/chili_age_5.txt" -Out out.png
# 注意：调色板行末尾必须【就是】6 位色值，不能跟注释（否则该色不生效）

# 渲染（真品 crop 模型已就位；TFC 贴图会自动从 jar 取）
& "$v/.probe/ref-tfc/render-tfc.ps1" -Model 'tfcfarmingplus:block/crop/chili_age_5' -Out a.png -YawDeg 40 -PitchDeg 28 -Scale 13 -AssetRoot "$v/.probe/lab-assets"
& "$v/.probe/ref-tfc/render-tfc.ps1" -Model 'tfc:block/crop/red_bell_pepper_age_6' -Out b.png -YawDeg 40 -PitchDeg 28 -Scale 13

# dump 任意贴图为字符网格（读画法最有效的办法）
#   先 extract 到临时目录，再用 System.Drawing 逐像素读并映射成字符

# 查看某物种被模型引用的贴图名：在 models 下 grep tfcfarmingplus:block/crop/ 后面的名字
```

**踩过的坑**：`.ps1` 必须 UTF-8 **with BOM**（`edit` 会剥离，改完必补 + `[Parser]::ParseFile`）·
`edit` 在同一文件被 pwsh 改写后必须**重新 read** 才能再 edit ·
TS 的 String.raw 模板里**不能出现美元符号加花括号、也不能出现反引号**（会破坏模板，写路径请用正斜杠）。
