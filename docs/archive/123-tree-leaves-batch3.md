## 二、逐物种：原型要点 → 画成什么 → 渲染后我看到了什么 → 还差什么

### kiwi 猕猴桃（大型落叶**藤本**）
- **原型**：宽卵形大叶、叶背灰白星状绒毛；花白色 5 瓣；果褐色卵形、密被绒毛、成串下垂；落叶。
- **画成**：主色**灰绿 sage（7 档 C6D1B6→364A29）**，明显脱饱和、整体偏亮 —— 全组唯一的"灰白毛感"色调；叶片画成柔和的宽卵形团块，亮点（S/G）堆在叶团一侧当叶背。
- **渲染后我看到了什么**：3D 下是一个**发灰发白的浅绿方块**，顶面近乎灰白，正面是柔和的灰绿暗斑，与其余 7 种的绿完全不在一个色系。果期是 3 个**带浅褐纵纹的棕色椭圆**（不再是木屑方块）。枯叶期整块转**浅卡其灰褐**。
- **还差**：叶团偏"软"，局部对比低于 TFC `orange_leaves`。曾试着罩一层 M 抖动提对比，结果 **2D 直接变成棋盘格**（已回退，见 §四-1）。

### lime 来檬（小乔木，**翼叶**是该属身份证）
- **原型**：卵状椭圆形叶、**叶柄有狭翅**；花白色小花；果小、椭圆、亮黄绿→淡黄。
- **画成**：主色**亮黄绿 chartreuse（A8D63E 起 5 档）**，全组最饱和最亮；用亮边（F）勾"小叶瓣 + 细颈 + 大叶瓣"的哑铃轮廓表现翼叶。
- **渲染后我看到了什么**：3D 是一块**高饱和黄绿方块**，顶面亮到接近荧光，暗洞零星；4 朵白花带黄心非常清楚。果期首版用 B8D42A —— **果和叶一个色，3D 里完全看不出来**，已改成**成熟黄（E0C830）加深色轮廓**，现在 3 个黄果一眼可见。
- **还差**：翼叶的"哑铃"在 3D 读不出来，只能读成"亮黄绿的叶团"；这是纯色方块几何的分辨率上限。

### loquat 枇杷（常绿小乔木，厚革质长叶）
- **原型**：**大而厚革质、倒披针形长叶**、侧脉 11-21 对直伸齿端、**叶背密被锈色绒毛**；冬季开白花成圆锥花序；果橙黄成串、顶端有宿存萼。
- **画成**：主色**深绿 6 档 + 锈色 R=9A5A22**；结构改成**一片片分开的长叶**：每片 4-5px 宽、6-9px 高、带 1px 亮中脉（F）与深色叶缘（C/D），叶与叶之间留透明空气。
- **渲染后我看到了什么**：首版是**贯通整高的竖条**，3D 里就是一块**竖条板 / 竹帘**（本轮踩得最重的一条）。第二版把间隙错位、又在三处加 DDF 深色断口，3D 变成"**一列列长短不一的深绿长叶、中间有暗缝**" —— 不再是竹帘，但**竖向感仍是全组最强**（枇杷现实就是长叶下垂，方向本身对）。
- **还差**：竖向连续感仍强于 TFC 的细碎点阵；锈色叶背只在果期贴图里靠 R 出现，叶片期基本看不到锈。

### lychee 荔枝（常绿乔木，**羽状复叶**）
- **原型**：羽状复叶 2-4 对、小叶披针形全缘有光泽、叶背带白粉；**花黄绿色**（不是米白）、圆锥花序顶生；果**红色球形、果皮有龟裂片**。
- **画成**：主色深绿，但把 **3 个复叶单元的小叶画成亮绿（F=6FB85E）**、叶轴与背景压到暗绿（C/D/E），靠明暗反差错出"成对尖小叶 + 一条轴"；花按原型用**黄绿（D8E070/EEF0B0）**的圆锥状花团；果用**正红 + 亮红龟裂点**、四角切掉做圆果剪影。
- **渲染后我看到了什么**：第一版小叶和背景同色，3D 下**整块糊成一团深绿**，什么结构都没有。改成"亮小叶 / 暗背景"后，3D 是**深绿块上散布亮绿叶簇**。花果期：3 处黄绿花团、3 颗红果（比首版的 3×3 红色便签圆得多）。
- **还差**：羽状复叶的"对生小叶"在 3D 尺度下仍读成"亮斑点"，不是"成对的小叶"。

### macadamia 夏威夷果（常绿乔木，**轮生窄叶 + 下垂总状花序**）
- **原型**：叶 3-4 枚轮生、长披针形革质；花**淡粉白色细长总状花序、成串下垂**；果绿色球形蓇葖果。
- **画成**：主色**冷调青绿 / 蓝绿（4E9070 系 6 档）** —— 全组唯一冷色相；用相邻两档浅色勾出 3 条"从节上放射"的窄叶；花期画成**之字形（每行左右错开 1px）的粉白垂串**，避开"1px 竖条=细柱"和"连成白色横梁"两个坑。
- **渲染后我看到了什么**：3D 是一块**明显偏青偏蓝的绿方块**，不会和任何一块混。花期最抢眼：**淡粉与白色相间的下垂点串**挂在青绿块上，一眼就是"垂下来的花序"，与其余 7 种的白花 / 橙花完全不同。果期是 3 颗**亮黄绿圆果**，在青绿底上非常跳。
- **还差**：轮生窄叶的"轮生"读不出来；垂串在 3D 下有点像"虚线"。

### mangosteen 山竹（常绿乔木，**极深墨绿 + 密平行侧脉**）
- **原型**：叶对生厚革质、**侧脉密集 40-50 对**；花**橙黄或红**（不是粉）；果**深紫黑球、顶部宿存绿色萼片**。
- **画成**：主色是全组**最深的墨绿（2E7A3C → 061C0E）**；用 2-3px 一组深浅交替做密侧脉，并把叶分成左右两片、中间留缝；花用**橙（E88A20）1px 花瓣 + 亮橙心 + 暗角**；果用**紫黑（4A1E4E/6E2E68/2A0E2E）+ 顶部两粒绿萼（2E6E2E）**。
- **渲染后我看到了什么**：3D 是**全组最黑的一块**，暗面几乎看不出绿色，只靠亮面的深绿细脉认得出。花是 3 朵**橙花带亮心**，在近黑底上极跳。果是 3 颗**紫黑球顶着绿萼** —— 4 个状态一眼认得出是同一树种。
- **还差**：密侧脉第一版是"贯通整高的竖线"，3D 下是**深绿灯芯绒**；第二版把脉打断成 2-3px 短划并加大量空气才缓解，但**竖向条纹感仍偏强**。

### medlar 欧楂（落叶小乔木，**果顶张开的花萼**是名片）
- **原型**：披针形钝叶、有绒毛、秋叶红棕→金橙；花**大、白、单生**；果褐色球形、**顶部 5 裂宿存萼张开呈杯状**。
- **画成**：主色**橄榄暗绿（86924C→242E12）**，全组最"土黄味的绿"；叶面用 F/E 交替做绒毛感的细碎对比；花用 1px 花瓣十字 + 黄心；果用**深赤褐（8A4A1E/A8622A/5A2E10/3A1C08）+ 顶部一排黄绿萼片（9AA84E）**。
- **渲染后我看到了什么**：3D 是**偏黄偏土的橄榄绿方块**（与 kiwi 的灰绿、papaya 的中绿都分得开）。花是 3 朵**白瓣黄心的十字小花**。果期首版是**棕色块贴在橄榄绿上、几乎看不见**；加赤褐加深轮廓 + 顶部黄绿萼后，3D 里能明确看到"**深褐果 + 顶上一撮绿萼**"。枯叶期是整组最漂亮的：**金橙色**。
- **还差**：叶片期的绒毛感在 3D 下仍读成"橄榄绿噪点"；宿存萼只有 1px 高，远看只是一个亮点。

### papaya 番木瓜（**草本 / 肉质茎，不是树**）
- **原型**：叶**掌状 7-9 深裂、可达 60cm**、叶柄长而中空；花奶油白、肉质、生于叶腋；果大型 10-30cm、绿→橙黄。
- **画成**：主色中绿（6BA855→142C12）；掌状叶画成**从中心放射的亮色臂（F）+ 臂间暗沟（E）**的星形，一株两处星；花用 1px 花瓣十字 + 黄心；果用**大块橙黄（E8A82A/F8C858）加深褐轮廓**呼应原型的"大果"。
- **渲染后我看到了什么**：3D 是**带亮臂条纹的中绿方块**，色调比 lychee/loquat 暖、比 medlar 正。花是 3 朵白瓣黄心小花。果是 2 大团橙黄 —— **8 种里果实最大的一块**，符合"木瓜 10-30cm"的比例。
- **还差**：**掌状深裂的星形在 3D 读不出来**，只读成"中绿带亮臂的纹理"。这是本轮自评最弱的一项（TFC `banana_leaves` 走的是"一整片大叶 + 大片透明"路线，若重做 papaya 值得试，但会掉出 156-206 的透明度带）。

## 四、本轮踩到 / 确认的坑

1. 🛑 **"提高局部对比"不能靠往主色里规则地撒第三档**：kiwi 原版柔和但有机，我撒了一层 M（8FA47D）提对比 ⇒ 2D 立刻变成**棋盘格**（3D 会成织物）。**已回退**。与 docs/122 里 amla"逐像素交替 → 斜纹织物"同源，但触发条件更隐蔽：**规则间隔**地撒第三档就会成格。
2. 🛑 **"贯通整高的竖条"再次确认**：loquat / mangosteen 第一版都是同一列的深浅交替走到 y15 ⇒ 3D 是**竹帘 / 灯芯绒**。改法：① 在若干行用 2-3px 深色断口打断；② 把 x0/x6/x12 这几个固定间隙列错开成 x1/x7/x13；③ 把长脉打断成 2-3px 短划。
3. ✅ **"果与叶同色会看不出来"再次实测**：lime 首版果 B8D42A 贴在叶 A8D63E 上 ⇒ 3D 里完全看不到果；medlar 首版棕果贴橄榄绿同理。改成高对比果色 + 深轮廓后一眼可见。
4. ✅ **1px 花瓣 + 亮心** 依旧是最可靠的"花"语法：medlar / papaya / mangosteen 首版用 3×3 实心块，3D 里是**彩色便签**；改成十字花瓣后立刻成花。macadamia 的**之字形错位垂串**同时避开了"1px 竖条=细柱"与"白点连排=横梁"。
5. 📌 **`draw2.ps1 -Species` 会写到 `textures/block/crop`**，**不是** `fruit_tree` ⇒ 树叶必须用 `-Design/-Out` 逐张落盘（本轮 32 张全部如此），且**全程没有用过 `-like "<sp>_*"` 批量匹配**。
6. 📌 **op 命中 156-206 需要"数着画"**：第一版 8 张里 5 张 op 在 210-235，靠手工补 30-50 个洞才落回带内。最终 op：kiwi 199-209 · lime 206-211 · loquat 185-192 · lychee 195-204 · macadamia 207-208 · mangosteen 172-181 · medlar 174-185 · papaya 193-201。
