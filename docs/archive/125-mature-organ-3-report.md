## 1. 逐物种：原型要点 → 画成什么 → 渲染后我看到了什么 → 还差什么

### 1.1 chive 韭菜（age5，单段）✅ 交付
- **原型**：丛生带状叶；**花薹自叶丛中央抽出、高出叶面，顶端是白色伞形花序（20~40 朵小花集成球状）**。
- **改前病根**（实测 dump）：整张只有 **1 个淡紫像素**（`B8A8E8` 在 y2x5），其余 62 个像素全是绿；3D 里是"一排等宽绿色栅栏"。
- **画成什么**（**迭代 5 版**）：
  - 最终版 = 原有叶丛**逐像素不动**，只在最高那根叶（x5 列）顶端加一朵 `D F D / E` 的小花（白-淡紫心-白 + 淡黄绿），并在 x9 列顶端补第 2 朵白花；
  - 新增色 `D=F4F9D5`（TFC 花白）、`E=D5E092`（TFC 花衬），保留原淡紫 `F`。
- **渲染后我看到了什么**：
  - `px/MO3-CHIVE-3D-v7.png`（p28/yaw40）：**一丛绿色竖叶，顶端 3 处白色小花**（十字几何把 x5 那朵复制成 2 处，加 x9 一朵），读作"开花的葱属植物"；
  - `px/MO3-CMP-2D.png` 第 1 对：改前顶端只有 1 个淡紫点，改后是"白-淡紫-白 + 右侧第 2 朵白花"。
- **还差**：**5 根叶仍是等宽平行竖条**（改前就有，本轮未动叶形）——3D 里像"栅栏"。

  🛑 **本轮最贵的一条教训（花了 5 版）**：**"顶端一团白花"在 `minecraft:block/crop` 十字板下画不出来**。
  - v1（12 个孤立白点悬在 y0~y3）→ 渲成"**碎纸屑**"；
  - v2（点加密成 DEDE 连排）→ 渲成"**一块米白奶酪扣在绿柱上**"；
  - v3（7 个点 + 花薹）→ 渲成"**白点围成的花环**"；
  - v6（白点与深绿叶尖交替）→ 渲成"**风车/雪花**"；
  - v7（**花紧贴叶尖、只有 2 处、每处 ≤3px**）→ 才读作花。
  - 根因：花点落在**贴图顶部的空白区**时，十字几何把它们在**两个平面上各画一次** ⇒ 视觉上围成环/板；
    只有当花**贴着已有叶体**（上下都有绿）时才读作"长在植株上"。
  - ⚠️ 顺带否掉一条我原本以为的规则："每行最多 2px"**不是**充分条件——
    v2 每行确实 ≤4px 却仍是"板"，因为 `D`(245) 与 `E`(216) **明度太接近**，
    视觉上连成一片。**同亮度连续也会成板**。

### 1.2 brussels_sprouts 抱子甘蓝（age6，maxAge=6）✅ 交付
- **原型**：粗壮直立茎，**叶腋密生小球（可食叶球，直径 2~4cm）**，自下而上渐小。
- **改前病根**（实测 dump）：主茎是 **`6E7A3A` 橄榄棕**（木杆色，1px 贯穿全高），
  **15 个像素的所谓"叶球"用的 `A9C86E`/`C8DE96` 与叶的高光同色** ⇒ 3D 里完全隐形，只看得到一根棕色杆。
- **画成什么**：
  1. 主茎色 `6E7A3A` → **`4E7A28`（绿）**：这是硬约束"主色不能抢走器官的对比色"的直接应用（eggplant 的紫茎同理）；
  2. 叶高光 `A9C86E`/`C8DE96` → **`8FB055`/`B0C878`（各降一档）**，让"最亮"这个位置留给叶球；
  3. 新增 `H=E8F2A8`，沿茎**左右交替放 5 个叶球**，每个 = `2px + 相邻行 1px` 的错开小簇（每行 ≤2px），紧贴主茎 x7。
- **渲染后我看到了什么**：
  - `px/MO3-BS-3D-v4.png`：叶丛拱形 + 中央**深绿主茎**，茎两侧**米白色的球块**清楚可见；

- **顺手修的**：改完 age6 主茎变绿后，**age0~age5 的主茎还是棕色** ⇒ 序列在 age5→age6 处**色相断裂**（同一根杆一龄之间从棕变绿）。
  已把 age0~5 的稿子做**纯色值替换**（`6E7A3A→4E7A28`、`A9C86E→8FB055`、`C8DE96→B0C878`）后重绘，
  **像素形状一个没动**。现在 age2~age6 七色完全一致，age6 只多一色 `E8F2A8`。
- **还差**：球做成 2~3px 后，在 22× 放大下是"**米白色小块**"而不是"圆球"——
  16×16 里画不出真圆；只能靠"数量 + 贴着茎交替"表达"茎上长满小球"。

## 3. 本轮可复用的画法结论

1. 🛑 **"顶端一团花"在十字板几何下画不出来**（chive 5 版学费）。
   花点若落在贴图顶部的**空白区**，会被两片板各复制一次 ⇒ 读作"花环 / 碎纸屑 / 风车"。
   **唯一可行 = 花紧贴已有叶体的尖端、只放 1~2 处、每处 ≤3px**。
2. 🛑 **"每行 ≤2px"不是充分条件**：亮度接近的两色（`F4F9D5` 245 与 `D5E092` 216）
   连排 4px，视觉上就是**一块板**。**同亮度连续同样成板**。
3. ✅ **器官跳出来的前提是底色让位**：
   - brussels 的**棕杆**（`6E7A3A`）必须回绿，叶高光必须降一档，米白球才可见；
   - hops 的球花必须比叶**亮一整档**（`92A95E`→`DCEAA8`），否则"结球果"完全读不出来。
   ⇒ 与 eggplant（深紫茎回绿）、common_bean（支架不入贴图）是**同一条规律**。
4. ✅ **多器官用"2px + 相邻行 1px 错开"的小簇**、沿主茎**左右交替**、**间距不等**，
   比"每行 2px 的等距横条"更像器官（brussels v3 的 5 条等距横条 → v4 的错开小簇）。
5. ⚠️ **改一张成熟龄 = 可能改出一段序列断裂**：brussels 只改 age6 主茎色，
   立刻在 age5→age6 处出现"棕杆变绿杆"。**改色板类改动必须回看整条生长序列**（`seq.ps1`）。
6. ⚠️ **LUM 出界不等于不合格**：`chive_age_5` LUM=143.4 被 `draw2` 标出界，
   但 TFC 自己的 **`garlic_4` LUM=147**、**`canola_5` LUM=137.2** —— 开花期作物本来就亮。
   指标只当"要不要再看一眼"的提示。
