# 135 · 阶段 5 干燥架试点交接

日期：2026-10-07

## 需求与独立设计

本阶段参考 Firmalife 已安装的干燥配方与干燥垫行为，只确认公开数据格式、露天条件、雨天重置和食品信息处理；没有复制 Firmalife 的业务代码。

| 需求 | 本项目实现 |
|---|---|
| 输入 | 一格食品，必须存在本模组 `drying` 配方；腐烂输入拒绝 |
| 环境 | 方块上方可见天空且当前不下雨；无天空时暂停，下雨时进度归零 |
| 计时 | 配方 `duration` 单位为 tick；服务端每 20 tick 推进一次 |
| 保存 | 内容物、进度和完成状态写入方块实体 NBT，区块重载后继续 |
| 装卸 | 手持物品放入；空手只能取出完成品；未完成时提示仍在干燥 |
| 完成 | 输出留在干燥架上，玩家取出后才进入背包；食品输出沿用输入食品时间信息 |
| 破坏 | 干燥中的物品或完成品随方块破坏掉落 |
| 空闲 | 空槽和完成状态不查配方、不推进计时 |

## 本批正式链条

- 姜 → 干姜：2400 tick。
- 姜黄 → 干姜黄：2400 tick。
- 白菜丝 → 干白菜：1800 tick。

每条产物都有 B 自己的物品注册、TFC food 定义、模型和语言键。干燥架提供 34 个 TFC/AFC 木材变体，共用一个方块实体类型。
