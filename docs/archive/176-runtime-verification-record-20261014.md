## 2026-10-15 实机反馈覆盖

用户本轮实机测试发现 B 木工配方没有在 JEI 中正常显示；移除 `tfcwoodwork` 后 B 自有木工系统无法使用，其他功能因此暂未继续测试。运行日志进一步显示木工世界交互 JSON 在 `InWorldRecipe.CODEC` 阶段解析失败，当前 `[JEI] Registered 1 in-world recipes` 只代表 1 条合法配方。故 D01、D02、D06 按“失败（当前版本）”处理，D03～D05 仍为“未测试”；本节覆盖下表中原先对木工的“未测试”静态占位。详细根因和重做安排见 [docs/177](177-runtime-feedback-and-silkworm-redesign-20261015.md)。

用户此前已确认**封窑、调味料、案板、旧版单件干燥架、草莓和可可主流程基本正常**；这些结论只适用于当时实际操作过的路径。木工当时“能用但未达到预期”，其后已重新开发。八件批量干燥、独立木工和养蚕没有收到当前版本的实机通过反馈。
