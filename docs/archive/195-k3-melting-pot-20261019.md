# K3 熔化锅与 Firmalife 巧克力混合物垂直切片（2026-10-19）

## 本轮目标

在 K3 面团与整派切片之后，继续实现“可可粉 + 甜味剂 → 巧克力混合物”的独立熔化流程。可可输入和输出沿用 Firmalife 原版注册 ID，不重新制作同名基础物品。

## 已完成

1. 新增 `melting` 配方类型和序列化器，配方保存两种输入、输出和熔化时间。
2. 新增 `melting_pot` 方块和 `MeltingPotBlockEntity`。方块实体使用 TFC `TickableInventoryBlockEntity<ItemStackHandler>`，包含可可粉、甜味剂和输出三个槽位。
3. 鼠标流程为：放入 Firmalife 原版可可粉、放入 TFC 甜味剂、空手右键开始熔化、完成后空手右键取出输出。熔化过程中禁止重复输入，腐坏或失效输入会停止并保留主输入。
4. 新增 `tfcagricultureplus:foods/melting_powders` 标签，目前接入 `firmalife:food/cocoa_powder`；输出使用 `firmalife:food/dark_chocolate_blend`。
5. 食品新鲜度由可可粉传递给输出；内容物、计时、失败状态和自动化访问均由 TFC 方块实体处理，不写入 blockstate。
6. 新增 JEI 熔化分类、熔化锅催化剂、Patchouli 中英文页面、语言、方块状态、模型和资源标签。

## 约束复核

- 没有复制 Firmalife 或示例模组的业务代码；只使用公开注册 ID、标签和既有 TFC 接口。
- 熔化锅通过 TFC 方块实体能力提供自动化访问；手动和自动输入都经过同一套槽位校验。
- 本轮没有启动 Minecraft，也没有宣称鼠标交互、JEI、保存/读档或 Firmalife 后续干燥流程已经通过实机验证。
