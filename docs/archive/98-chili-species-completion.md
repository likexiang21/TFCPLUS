# 第 45 轮：按风格规范完善一个物种 —— chili（辣椒）

> 用户指令：**「选一个物种进行完善，自主权交给你，做出合适的成果再停止」**。
> 执行依据：`moddev/docs/97-tfc-crop-style-spec.md`（TFC 风格规范）。
> 选 chili 的理由：它是茄科果菜，**TFC 里有同形态族的 `red_bell_pepper` / `yellow_bell_pepper` 可逐龄对照**；
> 标志器官（红辣椒）极其明确，正好用来检验规范能不能落地。

---

## 一、动手前的状态（问题）

我方 `chili_age_0..5` 与 TFC 同族对照后看到的：

| | TFC 甜椒 | 我方 chili（原状） |
|---|---|---|
| age0~2 | 一个小芽 → 展开成一小丛叶 | 2~3 个孤立点 |
| age3~4 | 居中成团的叶丛，age4 开出白花 | 几根细杆 |
| age5~7 | 结出显眼的红/黄大果 | **一丛细长的绿竖条，像杂草，一个果都没有** |

⇒ **根本没有标志器官，形态也不是茄科的灌木，而是禾本科式的细杆** —— 拿借来的形状凑数的结果。

## 二、动手前的准备（按规范的两步）

1. **查真实株型**：辣椒 = 一年生半灌木、**多歧分枝**、**叶互生卵形**、花白色单生、
   **果实俯垂（垂下来）**、细长指状、成熟红色。
   ⇒ **"果实俯垂"正是与甜椒最大的画法差别**（甜椒是圆润大果挂在中上部）。
2. **dump 同形态族**（TFC `red_bell_pepper_4/5/6`）逐行读画法：
   - 叶丛**上窄下宽、底端收成一个点**
   - **花是近白色的小点，散布在叶间**
   - **果是一整组红色阶**
   - ⚠️ **关键**：它每行也有 12px 的连续段，但用了 **24~30 档极相近的绿**，
     靠"每个像素的绿都略有不同"造出**叶片层叠的通透感**

## 三、五版迭代（每版渲染后看到的）

| 版本 | 我看到的 | 结论 |
|---|---|---|
| v1 | **一整块实心绿**（上窄下宽的绿色实体），叶丛里一个缝隙都没有；高光成一条规则斜线；果实是 2×3 红方块贴在底部 | ✗ 正是规范点名的"一堵墙" |
| v2 | 有洞了，但**还是两块实心绿** | ✗ 只加洞不够 |
| v3 | **通透多了**，深浅绿逐像素打散后能看到层次 | ✓ 找到根因：**通透感来自色阶打散，不是洞的数量** |
| v4 | 有主茎和垂果（**像辣椒了**），但太稀疏、果实偏大，叶子几乎没了 | ✗ 成熟期应是"长成的植株" |
| v5 | **叶丛饱满有层次 + 两侧各垂一根细长的红辣椒**，底部露出主茎 | ✓ **定稿** |

⇒ **v3→v4→v5 之间最大的认识转变**：我一开始在画"**甜椒的形状 + 红色的果**"——
甜椒才是紧凑叶团，而辣椒是**主茎直立、上部二歧分枝、叶较稀疏、果实从分叉处下垂**。
**物种差异要靠株型表达，不能靠换个果色。**

## 四、当前成果

六龄齐备（`chili_age_0..5` 已落盘，原版备份于 `.probe/texture-design/bak-chili-20260926/`），
证据 `.probe/texture-design/px/CHILI-6AGE.png` / `CHILI-V5.png`，设计稿在
`.probe/texture-design/px/chili_work/chili_age_*.txt`（自包含、可复核、可重画）。

**生长序列**（六龄矩阵看到的）：两个小点 → 子叶十字 → 立起主茎 → 分出侧枝 → 开出白花 → 叶丛挂红辣椒。
逐龄变大、器官延续 ⇒ **是同一株植物在长**。

## 五、第二轮优化（用户「继续优化」）

### 5.1 去对称：age0~4 全部重画
原稿的幼龄是**左右对称的十字/树形** —— 规范明确禁止"刻意对齐"。
真实植株长出来左右本就不一样，改法：
- **子叶一大一小、一高一低**
- **真叶互生错开**（不是左右各一片的十字）
- **分枝左右长短不一**（左侧枝抽得更长）
- **花的位置和数量都不对称**（3 朵，左右高度不同）

⇒ 六龄矩阵看到的（`px/CHILI-6AGE-2.png`）：每龄都是自然倾斜的形态，镜像感消失。

### 5.2 修复 age4 → age5 的生长断崖
去对称后 **age4 只有 25 个不透明像素，age5 是 85** —— 中间是断崖，age4 撑不起"成株开花"。
改法：**age4 直接采用 age5 的叶丛**（整体下移一行，比 age5 少顶端一行），
**去掉全部果实、在叶腋加 3 朵白花** ⇒ age4→age5 只差"花变成果"。
⇒ age4 变成 77，序列从 4/7/12/18/**25**/85 变成 **4/7/12/18/77/85**（`px/CHILI-6AGE-3.png`）。

## 六、仍然存在的问题（诚实记录）

1. **age3(18) → age4(77) 仍是 4 倍跳**（TFC 同族相邻龄的跳约 2 倍）。
   6 龄装不下"幼苗 → 成株"的完整过渡；要么把 age3 画得更接近成株，要么接受这个阶段性跳跃。
2. **age5 叶团轮廓仍偏"三角"**，逐像素起伏不足。
3. **age4 的白花放大后像白方块** —— 1px 的白点在这个尺寸下还不太"像花"。

## 六、这轮验证到的方法（可复用）

1. **规范是能落地的**：从"查株型 → dump 同族 → 设计 → 2D+3D 渲染 → 对照 → 迭代"一条链走通，
   五版之内能把一个"像杂草"的贴图变成"像辣椒"。
2. **"密而透"的实质是色阶逐像素打散**，不是往实心块上戳几个洞。
3. **物种差异优先用株型表达**（主茎、分枝方式、果实着生方式），换颜色是最弱的区分手段。
4. ⚠️ **反面教训**：我自己手写的幼龄稿**天然倾向于画成左右对称**，
   下一轮必须在设计稿阶段就刻意打破对称。
