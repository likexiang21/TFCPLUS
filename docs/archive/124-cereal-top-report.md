## 2. 两条硬约束（沿用上一组 + 本轮补充）

1. 🛑 **只换色阶、不挪列** —— `_bottom` 的 row0 ≡ `_top` 的 row15，
   **挪列会让秆在方块交界处横跳一格**。⇒ 本批**所有编辑像素的 alpha 与改前逐字节相同**
   （`maskVsBak = 0`，16/16 实测），**row15 一个像素都没动**（`row15Diff = 0`，16/16）。
2. ✅ **校准依据（上一组实测 TFC）**：`sugarcane_7_bottom` / `papyrus_5_bottom` 的秆也贯穿全高，
   但用**两档色阶沿长度交替画成"节"**。
   ⇒ 本轮继续沿用，并按**每列不等长、不同相位**分配序列（避免所有列同相位 = 又成规律网格）。

### 🆕 本轮新增的四条（写进后续同类任务）

1. **接缝行的颜色是冻结的，末段必须与它异色。** `_top` y15 与 `_bottom` y0 同色且都不能动，
   所以贯穿柱的最后一个"节"若与 y15 同色，跨接缝就是 3 行连续（`_top` y14/y15 + `_bottom` y0）。
   ⇒ 每条柱的序列末端**必须换档**（本轮 16 张都按此设计）。
2. **穗区的"多行完全相同"是第二类竖段来源，且不能用整行交换去修。**
   `amaranth_age_6/7_top` 的穗底有 3 行 / 5 行**逐像素完全相同**（`....RSRTRSRT....`），
   这直接让 c4-c11 全部 3-5 连。
   我第一版把其中一行换成"两两交换"的 `....SRTRSRSR....` —— 2D 一看，**红球上多了一条横向浅色分界带**（整行同时换档）。
   ⇒ 正确做法：换成一个**逐列错开、行内又无相邻同色**的交错行（本轮用 `....STSRTRSR....` / `....TRSRSRTR....`），
   断点分散到不同行，不形成横带。**这是"相位错开"在行方向的同一原理。**
3. **落盘前的"设计稿级 runs 预检"值回票价。** 本轮预检抓到 **3 处我自己写错的列索引**
   （例：`fox…_a7` 的 row14 `.....H.DDGE.H...` 里 H 在 x5 与 x12，**x9 是 G**，我却按 x9 设计了 H）。
   ⚠️ **教训：16 字符行里靠肉眼数列极易错位**，必须用脚本读回**列串**（本轮 `ct-verify.ps1` 会直接打印
   `c11=4(G:B.GDGGGGDDGDDGDG)` 这样的整列符号串，一眼看出真假阳性）。
4. **工具坑：`rr-review.ps1` 的 `-Out` 必须传绝对路径。** 传相对路径 `.probe\texture-design\px\X.png`
   会被**二次拼接**成 `.probe\texture-design\.probe\texture-design\px\X.png`（静默落到错目录，`Test-Path` 报 False）。
