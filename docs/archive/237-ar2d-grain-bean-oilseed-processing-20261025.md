# AR2-D：现有谷物、豆类和油料的加工与食品信息

日期：2026-10-25。预期复杂度5/5，实际5/5。当前切片的实现、静态检查、离线构建和成对部署完成；全部实机项仍待用户确认。没有启动游戏、运行单元测试或生成PCL压缩包。

## 一、本批范围和实际结论

审查13种谷物、11种豆类、3种油料，共27种现有收获物，及项目已有13份搅拌碗面团配方。种植、野生采收、盆栽的物品编号一致，本批没有改产量、种子、营养值或旧存档字段。

确认的缺陷是高粱食品分类遗漏，以及项目搅拌碗配方未传递食品历史、部分原料未拒绝腐烂。另为三种小麦补上合理的原生磨粉入口。其余专属面粉、榨油链仅列缺口，没有用错误品种的物品替代，也没有宣称完整农业加工开发完成。

## 二、修复与设计

### 高粱分类

高粱食品数据一直提供谷物营养，但原公共标签把它列为蔬菜。现在从项目的c:foods/vegetable移入c:foods/grain，并同步gen-tags.ps1，谷物成员12→13。标签仍replace:false，不改其他模组成员。

这会使高粱遵守原生谷物而非蔬菜用途：不再借蔬菜标签进入汤、沙拉、三明治，堆肥按中档绿料处理。TFC的汤料标签本来就不接受全部生谷粒，不能为了表面闭环把整个谷物标签加入汤料。原生生扁豆的汤料排除也保持。

### 三种小麦磨粉

B新增recipe/quern/spelt_flour、emmer_flour、einkorn_flour三份自有配方。每份相应收获物在原生TFC手磨得1份tfc:food/wheat_flour；拒绝腐烂原料，以tfc:copy_food保留原料食品历史及原生处理规则。三者均为小麦，不把其他谷物冒充大米或玉米。

已有小麦粉可继续用于TFC/Firmalife面团、项目搅拌碗及后续案板流程。没有新增小麦粉、基础面团、设备或物种。手磨设备、磨石消耗、JEI分类由原生系统负责，实际显示及操作待验。

### 13份搅拌碗食品历史

现用Firmalife 3.0.15的MixingBowlRecipe直接复制静态结果；其搅拌完成流程没有把输入食品历史传给产物。原料中的面粉已有部分not_rotten约束，但六份发酵面团的甜味剂，以及蛋糕面团的鸡蛋和甜味剂没有相同约束。仅修改JSON无法给该静态结果添加TFC的食品历史转换。

独立新增FoodMixingBowlRecipe，通过公开继承接口继续使用原生匹配、原生RecipeType、搅拌碗实体和Firmalife JEI分类。只为项目13份配方注册自有序列化器tfcagricultureplus:food_mixing_bowl，不修改第三方配方或注入其类。数据和网络均有编解码器，限制1～5个原料，物品输出不得超过原生5槽容量。

匹配和组装均检查腐烂；产物先获得真实日期，再调用TFC公开updateFoodFromAllPrevious，按原生算法携带最早投入食品的历史及腐烂速率换算。不是简单复制绝对日期，也不自行重写营养或腐烂公式。此多原料API不等于合并所有原料营养/特性；产物保留对应原生面团的食品定义。

扣物品、用液体、返还容器及动画仍全由原生搅拌碗执行。本类不修改库存或液体，避免双扣。完成搅拌前原生设备会重新匹配，过程中原料腐烂应拒绝完成，尚需实机确认。

13份配方ID不变。六谷物的小麦、大麦、黑麦、燕麦、玉米、大米粗面团仍用100mL水＋对应面粉，产出1份原生TFC面团；发酵面团仍用100mL酵种＋对应面粉＋甜味剂，产出1份原生Firmalife面团。蛋糕面团仍为300mL酵种、三份既定面粉标签、鸡蛋、甜味剂，产出1份原有蛋糕面团。没有新增其他面团，没有恢复删除的面团台或熔化锅，没有删除工作台配方。

### 说明与未开发边界

中英文简介保留前4页、锚点及旧跳转，分别追加谷物加工、豆类与油料两页；生成模板同步，新页共4页，手册总页数1378。

11种豆类及芝麻、红花、向日葵现有食品均通过蔬菜标签成为原生汤/沙拉/三明治候选，仍受设备和食品规则约束。没有把“有候选标签”写成玩家已验收。向日葵现有食品没有宏量营养组，已如实列入矩阵；原生面粉也存在无宏量营养组的定义，不能仅据此擅自重配数值。

10种非小麦谷物仍缺专属磨粉链；三种油料尚无专属榨油链。保留可食用和堆肥用途，不磨成菜籽糊冒充其他油，不新增完整面粉/油品系统。
