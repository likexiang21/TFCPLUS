# B 阶段：独立木工系统迁移与工作台契约计划

**日期：** 2026-10-13  
**状态：** 计划已冻结，已开始源码与资源审计；本阶段目标是把 TFC Woodworking 的木工内容迁入 B 模组，由 B 独立注册、独立加载、独立运行。

## 用户确认的最终口径

木工不再作为 TFC Woodworking 的附属功能。TFC Woodworking 的 MIT 许可允许项目迁移和参考其代码；施工时保留许可证与版权声明，并将代码、资源、配方和注册 ID 改为 `tfcagricultureplus` 自有内容。

B 必须在没有 `tfcwoodwork` JAR 的环境中正常加载和运行。TFC Woodworking 可以作为迁移来源和对照对象，不能成为 B 的运行时前置。

## 必须保持的全局要求

- 不直接复制其他示例模组的业务代码；本次仅按用户明确的 TFC Woodworking 特殊豁免迁移其木工内容。
- 所有木工配方使用项目自己的注册 ID、序列化器、资源路径和 JEI 类型。
- 覆盖 TFC 20 种木材和 AFC 14 种木材，共 34 种木材。
- 原木先去皮，再进入劈木、锯木、支撑木、四分木、木料堆和副产物流程。
- 所有能放置或存储物品的方块继续使用 TFC `InventoryBlockEntity` / `TickableInventoryBlockEntity`、保存协议、同步机制和标准 item handler。
- 工作台配方遵循 TFC 的 `TFCWorkbenchContainer` / `CraftingMenu` 契约，并使用 `#tfc:workbenches` 标签。
- JEI、Patchouli、创造页和实际配方来自同一套 B 注册清单。
- 旧 B 注册和旧区块引用保留必要的兼容读取，不直接删除可能导致旧存档丢失的 ID。

## 施工阶段

### B-0：来源、许可和环境冻结

1. 从当前安装的 `tfcwoodwork-1.21.1-1.2.4.jar` 建立文件清单、版本和 SHA-256。
2. 记录迁移范围：Java 类、配方类型、配方序列化器、配方 JSON、木料方块、物品、标签、燃料、声音、模型、语言和许可证。
3. 保留 MIT 许可证和来源说明；不迁移没有明确许可的第三方素材。
4. 备份当前 B 源码、资源、部署 JAR 和旧木工配方。

### B-1：独立木工核心

1. 将 `in_world` 配方类型、编码器、解码器、缓存和处理器迁移到 B 的包和命名空间。
2. 将目标方块替换、工具判定、副产物投放、声音和耐久消耗改为项目自己的实现。
3. 删除当前 B 对 `tfcwoodwork:*` 配方、物品和方块的运行时引用。
4. 保持 B 单独运行时不需要加载 TFC Woodworking。

### B-2：独立木料内容

1. 独立注册去皮原木、半木、四分木、树皮、韧皮、锯末和木料堆内容。
2. 为 20 种 TFC 木材和 14 种 AFC 木材补齐模型、方块状态、掉落、语言、燃料和工具标签。
3. 迁移 TFC Woodworking 的木工配方语义到 B 自有配方 ID，并修正历史上“原木直接变大量木板”的错误路径。
4. 统一整原木、半木、四分木、木板、支撑木和木料堆的数量关系。

### B-3：工作台契约

1. 当前阶段复用 TFC 已有的 20 种工作台，不新增 B 自有工作台方块和菜单。
2. 项目木工工作台配方使用原版 `RecipeType.CRAFTING` / TFC 工作台容器能够检索的配方格式。
3. 复用的 TFC 工作台继续由 `#tfc:workbenches`、`TFCWorkbenchContainer` 和 8 格距离规则负责有效性。
4. 若后续决定新增 B 工作台变体，必须覆盖 34 种木材，并等效实现 TFC 工作台菜单提供逻辑，不能只注册方块和标签。
5. 工作台配方不能依赖 TFC Woodworking 的配方类型或菜单类。

### B-4：容器、自动化和存档

1. 审核木料堆、工作台、蚕架和后续所有放置物品方块的 TFC 容器接口。
2. 统一手动交互、自动化插入、自动化取出、保存重载、同步和破坏掉落。
3. 为已有旧 B 木料 ID 制定读取和迁移表；旧内容只能在确认有迁移路径后再清理。

### B-5：显示、兼容和构建

1. JEI 只显示 B 自有木工配方；Patchouli 使用 B 自有 ID 和说明。
2. 创造模式只显示 B 正式木工物品，旧兼容物品保留读取但隐藏。
3. 在没有 TFC Woodworking 的独立实例中执行 A/B clean build、边界门禁、资源台账、配方注册和 JAR 哈希检查。
4. 在安装 TFC Woodworking 的环境中额外检查重复配方、重复 JEI 入口和重复交互；不能用隐藏 JEI 掩盖实际重复处理。

## 阶段验收条件

- 不安装 TFC Woodworking 时，B 能加载、进入世界并完成木工流程。
- TFC 和 AFC 34 种木材均能完成去皮、劈木、锯木和木料堆流程。
- 原木不会绕过去皮步骤直接产生异常数量木板。
- 工作台配方能在 TFC 工作台中检索和取出，普通工作台规则不被破坏。
- 工具耐久、产量、副产物、燃料、自动化和保存重载符合记录表。
- JEI、Patchouli、创造页和实际配方一致。
- 用户实机确认画面、交互和木工流程后，才标记 B 木工阶段完成。

## 当前执行入口

当前先执行 B-0 来源与注册审计，再执行 B-1 核心迁移。旧 B 木工源码和资源在迁移完成前保留，避免中途破坏当前可用的干燥架、封窑和食品流程。
