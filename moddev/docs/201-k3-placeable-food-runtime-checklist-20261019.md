# K3 可放置食品统一实机验证清单（2026-10-19）

## 一、验证范围

本清单覆盖当前 K3 已完成的八个环节：面团成型台、熔化锅、整派、整蛋糕、整奶酪、黄油块、果冻块和糖块。本轮只记录待用户实机确认的行为，不把静态构建结果当作运行通过。

使用的部署包：`mods/TFCAgriculturePlus-NeoForge-1.21.1-0.1.0.jar`。

启动脚本：`moddev/tools/launch-client.ps1`。如果脚本无法保持客户端窗口，可改用 PCL 启动同一实例；不需要安装 TFC Woodworking 才能验证本项目的木工和厨具内容。

## 二、启动与内容可见性

- [ ] A01：客户端能进入主菜单并保持运行。
- [ ] A02：进入测试世界后没有注册冲突、方块实体异常或资源加载致命错误。
- [ ] A03：创造模式物品栏能看到面团成型台、熔化锅、整派、整蛋糕、整奶酪、黄油块、果冻块、糖块及对应小份物品。
- [ ] A04：JEI 能搜索到上述方块和小份物品，名称、图标和命名空间正确。
- [ ] A05：Patchouli 厨房条目能打开，中文和英文页面均能显示 K3 的八个流程。
- [ ] A06：移除 TFC Woodworking 后，K3 方块、配方、JEI 和手册仍可加载。

## 三、配方与标签

- [ ] B01：`c:foods/flour` 中的有效面粉可放入面团成型台，能成型并取出面团。
- [ ] B02：面团、水果、甜味剂和鸡蛋能合成整蛋糕；输入数量和输出数量正确。
- [ ] B03：四个 Firmalife 奶酪标签物品能合成整奶酪。
- [ ] B04：四个 Firmalife 黄油能合成黄油块。
- [ ] B05：四个 `tfc:foods/jam` 标签物品能合成果冻块；至少用两种不同果酱分别验证。
- [ ] B06：四个 `tfc:foods/sweeteners` 标签物品能合成糖块；至少用两种不同甜味剂分别验证。
- [ ] B07：熔化锅接受 Firmalife 原版可可粉和 TFC 甜味剂，完成后输出 Firmalife 原版黑巧克力混合物。
- [ ] B08：JEI 能从原料跳转到整块食品，再跳转到对应小份；没有显示失效旧 ID 或重复配方。

## 四、放置与分餐

分别对整派、整蛋糕、整奶酪、黄油块、果冻块和糖块执行以下项目：

- [ ] C01：手持整块食品右键地面可以放置，选择框和碰撞箱位置正确。
- [ ] C02：空手右键可以取出一份对应小份，方块仍保留。
- [ ] C03：连续取用直到剩余份数为零，最后一份取出后方块正确消失。
- [ ] C04：取用过程中不消耗错误物品、不生成额外物品、不吞掉玩家手中物品。
- [ ] C05：不同食品不会取出错误类型的小份。

份数核对：

| 食品 | 初始份数 | 目标输出 |
|---|---:|---|
| 整派 | 8 | 派切片 |
| 整蛋糕 | 6 | 蛋糕切片 |
| 整奶酪 | 6 | 奶酪切片 |
| 黄油块 | 6 | 黄油片 |
| 果冻块 | 6 | 果冻切片 |
| 糖块 | 8 | 糖块小份 |

## 五、保存、破坏与自动化

- [ ] D01：放置整块食品后退出世界，再次进入，剩余份数保持不变。
- [ ] D02：取用一部分后保存、退出并重新进入，剩余份数和食品类型保持正确。
- [ ] D03：未取用的整块食品被破坏时，掉落内容符合当前实现，不丢失食品。
- [ ] D04：已取用部分的方块被破坏时，只掉落剩余小份，不凭空恢复完整方块。
- [ ] D05：熔化锅退出、读档后输入、计时和输出状态保持正确。
- [ ] D06：容器自动化输入不能绕过槽位校验、配方标签和输出限制。
- [ ] D07：腐烂输入或不匹配输入失败时，原料、工具耐久和已有份数保持不变。

## 七、记录格式

每一项使用“通过 / 失败 / 未执行”标记。失败时记录：

1. 使用的原料 ID 和数量；
2. 操作顺序以及是否保存、退出或重进世界；
3. 实际输出、剩余份数和屏幕表现；
4. 截图或日志位置。
