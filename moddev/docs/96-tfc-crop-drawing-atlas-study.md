## 一、按形态族看：TFC 怎么画每一类

### 1. 禾本科 —— `barley` `oat` `rice` `rye` `wheat`
- **苗期（age0）**：只有 **2~5 个极小的点/短竖条**，**贴着贴图底边**
- **中期**：逐龄**长高加密**，变成一丛**竖直细秆**，**秆与秆之间留着明显缝隙**（不是一片实心绿）
- **成熟期（age6/7）**：**整株从绿变成金黄/枯褐**，**顶端结出一层浅黄色的穗**
- 特例：`sugarcane` 的秆**粗到 2px**、**紫红色**（甘蔗的紫皮），全高贯穿；
  `papyrus` 顶端有一团**棕色刷状花序**

### 2. 根茎类 —— `beet` `carrot` `radish` `potato` `cassava` `onion` `garlic`
- **上部**是绿色叶丛；**成熟期才在底部冒出彩色根块**
  - `carrot` → **橙色**粗根　`beet`/`radish` → **紫红色**　`potato` → **棕色块茎**　`cassava` → 棕色木质茎
- `onion`/`garlic` 是**细长的管状绿叶**，竖直、不带根块

### 3. 果菜类 —— `red_bell_pepper` `yellow_bell_pepper`
- 先长**叶丛** → **age4 开出白色小花** → **age5 起结出红/黄大果**（果实是画面里最跳的一块）

### 4. 叶菜类 —— `cabbage`
- 从几个像素起，**逐龄滚成一个圆润的叶球**，形态始终是"一团"

### 5. 匍匐类 —— `melon` `pumpkin` `squash`
- **横向铺地生长**（不是往上长），后期出现**黄色大果**

### 6. 开花作物 —— `canola` `alfalfa` `soybean`
- `canola`（油菜）：绿叶之上**撒满黄色小花**，成熟时几乎整株是花
- `alfalfa`（苜蓿）：细碎绿叶 + **age5 起加紫色小花**
- `soybean`：**稀疏**的分枝株，株上点**黄色小花/荚**，age6 **枯成棕色**

### 7. 豆科碎点丛 —— `lentil` `peanut`
- 从底部分枝的**碎点枝叶丛**，密而透

### 8. 攀援类 —— `tomato` `green_bean`
- **age3 起出现棕色支柱**，枝叶缠绕其上

## 二、最重要的三条规律（我看到的）

### ① 成熟期一定有一个"一眼能认出的标志性彩色器官"
| 类群 | 标志器官 | 颜色 |
|---|---|---|
| 禾本科 | 穗 | 金黄 / 枯褐 |
| 根茎类 | 根块 | 橙 / 紫红 / 棕 |
| 果菜类 | 大果 | 红 / 黄 / 绿 |
| 开花作物 | 花 | 黄 / 紫 / 白 |
| 攀援类 | 支柱 | 棕 |

**底色始终是绿色系，标志器官一律用对比色。**
⇒ 这张贴图要能回答玩家两个问题：**这是什么？熟了没有？**

### ② 六龄是"同一个器官系统在长大"，不是每龄换一套东西
苗期永远是**贴着底边的 2~5 个小点** → 中期**逐龄加密加高** → 成熟期**长出标志器官**。
（这正是用户最初批评"不能看做一个植物"的那条标准。）

### ③ 竖向/横向的走向是物种设定的一部分
- 禾本科、管状叶（onion/garlic）、甘蔗 → **竖直**
- 匍匐类（melon/pumpkin/squash） → **横向铺展**
- 叶菜（cabbage）、果菜（pepper） → **居中成团**

## 三、可以立刻用在画新物种上的判断

1. **先想清楚这个物种的"标志性器官"是什么、在哪一龄出现、什么颜色** —— 没有这个，成熟期就是一团绿。
2. **苗期不要画多了**：2~5 个小点，贴底边。
3. **成熟期不要画成实心块**：禾本科是"带缝的细秆丛"，豆科是"碎点丛"。
4. **变色是合法且有力的手段**：禾本科成熟直接整株转金黄，这是 TFC 明确在用的语言。
5. **花/果是后加的**：age4 开花、age5 结果，不要一开始就画上去。

## 四、变体贴图（161 张）—— 又读出三条规律

### 4.1 枯死形态（`_dead` / `_dead_young`，68 张）：换色为主，两类例外
- **枯死 = 整株换色（绿 → 枯黄/褐），形态基本保留**：`barley_dead` 仍然是竖直细秆，只是整株变金黄；
  `oat_dead` / `rye_dead` / `wheat_dead` 同理
- **苗期枯死只有 3~8 个小点**（`alfalfa_dead_young` / `cabbage_dead_young`）
- **两类例外，共同点是"收获物必须留下"**：
  - **根茎类掉叶留根**：`beet_dead` / `carrot_dead` / `radish_dead` 枯死后上部叶消失，
    只剩**紫红 / 橙色**的根块
  - **果菜类保留果实**：`red_bell_pepper_dead` / `yellow_bell_pepper_dead` 还挂着红 / 黄果
- ⇒ **游戏功能决定画法**：玩家必须一眼看出"这株还能不能收"

### 4.2 双段作物（`_top` / `_bottom`，45 张）：接缝就是生命线
- `green_bean` / `tomato`：**bottom = 棕色支柱 + 下部叶；top = 支柱顶 + 上部叶（tomato 带红果）**
- `maize`：**bottom = 横向铺开的宽大叶片；top = 顶端的浅色穗**
- `papyrus`：**bottom = 细秆；top = 顶端棕色刷状花序**
- `sugarcane`：**紫红色粗秆**贯穿两段
- `jute` / `rice`：上下都是密秆
- ⚠️ **bottom 的顶行必须和 top 的底行对得上**，否则渲染出来中间断开
- 另有 `stick_top`（棕色支柱顶）、`rotten_melon_top` / `rotten_pumpkin_top`（棕褐色腐烂瓜）

### 4.2b ⚠️ 双段作物必须【拼起来看】（用户 2026-09-26 指正）
把 `_bottom`（下）+ `_top`（上）上下拼成 **16×32 的整株**再排矩阵
（产物 `.probe/texture-design/px/TFC-JOINED.png`）—— **每个物种的株型一眼可辨**；
分开并列时我只看到两堆绿像素，**完全读不出形态**：

| 物种 | 拼成整株后看到的 |
|---|---|
| `green_bean` | 一根**棕色支柱**贯穿，绿叶攀附两侧，逐龄变密 |
| `jute` | **一丛细高的竖直绿秆**（5~6 根）；**下部是纯秆、上部才长小叶** |
| `maize` | **一根主秆 + 两侧下垂的宽叶**，**中部结着黄色玉米棒**（不是顶端），顶端是深色花序 |
| `papyrus` | 底部是**粉褐色的基部**（不是绿色），中部绿细秆，**顶部放射状伞形花序** |
| `sugarcane` | **紫红色粗秆**（2px）贯穿，**顶部才是绿色叶丛** |
| `tomato` | **棕色支柱**为干，绿叶沿干生长，age7 上部**挂红果** |

⇒ **判据：双段作物的验收必须拼成整株看。** 接缝对齐只是最低要求，**株型连贯才是目的**。
⇒ 我方双段作物（`seam-audit.ps1` 只管接缝对齐）今后也要照此**拼图检查**。

### 4.3 野生形态（`_wild`，45 张）：约等于"成熟态带标志器官"
- `carrot_wild` 有橙根 · `beet_wild` 有紫红根 · `radish_wild` 有紫红根 ·
  `red_bell_pepper_wild` / `yellow_bell_pepper_wild` 挂着红 / 黄果 ·
  `barley_wild` / `oat_wild` / `rye_wild` / `wheat_wild` 是金黄枯草 · `canola_wild` 满株黄花
- **`_stick` 是一套独立的棕色支柱贴图**，从苗期（`green_bean_0_stick` / `tomato_0_stick`）就存在
  ⇒ 攀援作物的"架子"先于植株存在，**不是画在植株贴图里的**
