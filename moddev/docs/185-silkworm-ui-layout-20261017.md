# 养蚕箱 UI 布局调整记录（2026-10-17）

## 调整目标

根据用户提供的参考图，养蚕箱界面使用统一的单格素材。素材只绘制在实际存在、可以交互的槽位上，空白区域保持背景色，避免让玩家误以为那里还有储存槽。

## 当前布局

- 生物槽：第一行 8 格，放置蚕种、蚕、蚕茧和成虫，每格只能放置一个生物物品。
- 饲料槽：第二行左侧 2 格，每格可堆叠 64 个允许的果树叶或桑叶。
- 蚕种输出槽：第二行右侧 1 格，只允许系统产出蚕种，位置与菜单槽位一致。
- 饲料槽菜单坐标已修正为第二行 y=54，与界面贴图位置完全一致；叶片图标和鼠标交互区域不再向上偏移。
- 生物槽、饲料槽和蚕种输出槽之间的空位不绘制格子素材。
- 玩家物品栏：使用 TFC 菜单接口的真实坐标绘制 27 格主物品栏（3 行 × 9 列）和 9 格快捷栏；其余区域不绘制格子素材。
- 四类区域分别显示“生物槽”“饲料槽”“蚕种输出槽”和“物品栏”标签，不再显示“箱子”标题。

## 同步的生命周期规则

- 蚕和蚕茧的成长不再受温度上下限限制。
- 蚕种孵化仍保留最低 0°C 条件，低于 0°C 不孵化。

## 实现文件

- `SilkwormRackScreen.java`：养蚕箱槽位、玩家物品栏槽位、背景素材和分类标签的绘制。
- `SilkwormRackMenu.java`：养蚕箱 8 个生物槽、2 个饲料槽和 1 个输出槽的菜单坐标。
- `textures/gui/silkworm_slot.png`：由用户提供的单格素材缩放得到的 18×18 槽位纹理。
- `zh_cn.json` / `en_us.json`：四类界面标签及空标题键的翻译。
- `verify-silkworm-lifecycle.ps1`：同步检查无成长温度限制、真实槽位布局和标签键。
