## 一、先把"原版"钉死：结构 + 杆的确切像素

### 1.1 结构（从 `mods/TerraFirmaCraft-NeoForge-1.21.1-4.2.10.jar` 导出核对）
```jsonc
// assets/tfc/blockstates/crop/green_bean.json
"age=0..3,stick=true,part=bottom": "tfc:block/crop/green_bean_age_N_stick",  // 下半格：植物 + 杆
"age=0..3,stick=true,part=top":    "tfc:block/crop/stick"                    // 上半格：纯杆
// assets/tfc/models/block/crop/stick.json
{"parent":"block/crop","textures":{"crop":"tfc:block/crop/stick_top"}}
```
本模组变体表与 TFC **逐条一致** ✓。`tfc:block/crop/stick_top.png` 的杆在 **x7/x8、只占该贴图 y8..y15**（上半格的下半段）。

### 1.2 杆的确切像素（TFC 全部插棍贴图共用同一套 16 行木纹）
逐像素读 `green_bean_0/1/2_stick`、`tomato_0/2_stick`、`stick_top` 后确认：
**TFC 所有贴图里的杆都是同一套图案**，差别只在"它自己的植物盖住了哪几行"。

| 行 | x7 | x8 | | 行 | x7 | x8 |
|---|---|---|---|---|---|---|
| y0 | `58481D` | `3E2F0A` | | y8 | `58481D` | `3E2F0A` |
| y1 | `58481D` | `3E2F0A` | | y9 | `513E0C` | `3E2F0A` |
| y2 | `58481D` | `513E0C` | | y10 | `513E0C` | `513E0C` |
| y3 | `513E0C` | `513E0C` | | y11 | `513E0C` | `513E0C` |
| y4 | `513E0C` | `513E0C` | | y12 | `58481D` | `513E0C` |
| y5 | `58481D` | `513E0C` | | y13 | `58481D` | `3E2F0A` |
| y6 | `58481D` | `513E0C` | | y14 | `58481D` | `3E2F0A` |
| y7 | `58481D` | `58481D` | | y15 | `58481D` | `3E2F0A` |

- 只有三个颜色：`58481D`（亮）`513E0C`（中）`3E2F0A`（暗）。
- y14 的 x7 是唯一在 TFC 全部贴图里都被植物盖住、无法直接读到的格子（推为 `58481D`，与 y12/y13/y15 连续）；其余 31 格**全部是 TFC 的原始像素**。

### 1.3 审计结果：**44 张里只有 4 张的杆与原版逐像素一致**
工具 `.probe/texture-design/stick-pole-audit.ps1`（新增，可复用）：

```
textures: 44   identical: 4   differ: 40
pole cells total: 995   wrong: 295          ← 30% 的杆像素与原版不符
RESULT: FAIL - pole pixels do not match TFC
```
典型错法：
- **整根杆挪了列**（`pea` x4,5 / `cowpea` x9,10 / `common_bean` x6,7 / `yam` x7,8,9）—— 见 §二，另一半是"上半格对不齐"；
- **杆的逐行木纹自己编**（`hops`/`yam`/`malabar` 的 x7,y0 是 `3E2F0A`，原版是 `58481D`；一错就是 12~15 格）；
- **杆色被植物色替换**（`bitter_melon`/`chayote`/`loofah`/`snake_gourd` 差 1~8 格，多为某一行把邻列的植物色写在杆上）。

### 1.4 因此的硬规则（写进派单，不可再"各画各的"）
1. **杆的像素必须逐格等于 §1.2 的表**：列 **x7/x8**、行 y0..y15、三色只用那三个。
2. 🛑 **禁止把杆列当物种区分手段**（这是上一轮豆科组犯的错）。
3. 物种差异**只能做在植物上**（叶形/叶色/茎的形态/器官）。
4. 植物可以（也应该，像 TFC 那样）**盖住杆的下部若干行**；被盖住的行不算"杆像素"，但**没被盖住的地方必须是原版像素**。
5. 验收：`& .\stick-pole-audit.ps1` 必须报 **identical: 44 / differ: 0**。

## 三、按**现实原型**画植物（用户同一条要求里的第二半）

| 物种 | 现实株型要点（用来定"叶形/叶序/器官"） |
|---|---|
| `bitter_melon` 苦瓜 | 攀援藤；**掌状深裂 5~7 裂**、裂片边缘有齿；花黄；果有瘤 |
| `chayote` 佛手瓜 | 生长旺盛的攀援藤；**宽大心形/阔心形叶**（叶最大最阔）；有卷须 |
| `loofah` 丝瓜 | 攀援藤；**掌状 5~7 浅裂**；卷须；果有棱 |
| `snake_gourd` 蛇瓜 | 细弱攀援藤；**叶深裂成细条**（最细碎）；花白色流苏状 |
| `hops` 啤酒花 | 缠绕茎；**掌状 3~5 裂、粗齿、叶面糙**；雌花是**淡黄绿色球状穗**（标志器官） |
| `yam` 山药 | 缠绕藤；**心形/箭形叶、叶脉明显（弧形脉）**，常对生 |
| `malabar_spinach` 落葵 | 肉质缠绕藤；**叶肥厚圆钝**；红茎品种**茎紫红** |
| `common_bean` 菜豆 | 缠绕；**三出复叶**（3 片小叶一组）；茎绿到紫红 |
| `cowpea` 豇豆 | 缠绕；**三出复叶**，小叶较窄；荚细长 |
| `pea` 豌豆 | 攀援靠**卷须**；复叶**小叶 + 卷须**；整体**蓝绿**、叶更窄 |
| `winged_bean` 四棱豆 | 缠绕；**三出复叶**；**茎有四条纵棱（翼）** |

**画法要求（沿用项目已有规范）**：
- 苗期 `age0` = 贴底边几粒 1~2px 嫩芽，上半留空；
- 逐龄是**同一株在长大**：茎锚同一列、后一龄在原有叶上方新增（不要另起一张）；
- 叶是**1~3px 的小枝叶**（不要 3px 以上大色块 —— 十字几何下会糊成实心墙）；
- 颜色是植物的绿、体积靠 2~3 档离散色阶，**不许近黑**。
