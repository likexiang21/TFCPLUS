## 已核对的行为与边界

### 普通单格

- 每种种子绑定对应作物；种子提示的 N/P/K 与气候引用和实际作物一致。
- 本批所有 Java 最大龄与资源显示龄、成熟掉落条件匹配，包括抱子甘蓝的 0～6 龄，以及荞麦、福尼奥米、单粒小麦、穇子等 0～7 龄；没有一律把所有作物当成 0～5 龄。
- 普通作物、野生作物和死株掉落均匹配自己的方块编号并有对应返种入口。
- 成熟产物与食品数据/分类吻合。草莓使用 TFC 原版食品；亚麻产物为纤维，非食品，其完整材料用途归 AR2 深查。
- 已有盆栽数据的输入、种子和产物与田间链一致；未接入的可选盆栽不因此判为田间种植阻断。

### 可重复采收

对象为辣椒、茄子、秋葵、芦笋、韭菜、大黄和洋蓟。

当前每项最大龄为 5，两个原生采收阶段均配置同一种项目食材。核对了已安装 TFC 4.2.11 的字节码及公开实现：近熟和成熟阶段可通过原生右键交互采摘；采摘后原生逻辑退回较低生长进度、清零当次产量，植株继续留在原位置。左键破坏则按掉落表收获并移除植株。

这属于 TFC 的采收与再生行为，历法、光照、气候、养分、寿命与枯死规则也继续归 TFC 管理。本批没有添加永久存活、冬季强制暂停、额外成熟计时器或修改原版周期。

### 重载与存档

源码核对确认 87 项作物均列入项目作物 BE 的有效方块列表；普通与可采收工厂继续绑定 `CropBlockEntity::serverTick`，成长状态继续由 TFC 作物 BE 保存。TFC 的随机刻用于正常生长结算，历法更新还处理时间跳跃/区块重载后的补算，不能把“时间差控制速率”误解为“不依赖随机刻”。

上述是绑定和接口证据，尚未实际执行区块卸载或旧存档回归。原有 NBT、BE 类型、作物注册与状态定义本批均未改变。
