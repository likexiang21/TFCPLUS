## 四、技术发现全表（**下一手必须沿用**）

### 4.1 几何
1. **`block/crop` = 4 片平行竖板，两对 x 偏移差 4** ⇒ ① 4~10px 宽 × ≥9 行高的实心块 → **门框**；
   ② 1px 封闭轮廓 → **圆环**；③ 同行左右各一叶 → 与 +4 副本并成**横梁**。"宽头+细柄""心形叶+叶柄"是**正常的**。
2. **叶球类 v12（用户认可的唯一正确解）**：
   - **整片大叶不许切条**（宽 8，与原版一致）；
   - 每片叶的**平面放在球的外表面**、**旋转原点设在叶根** ⇒ 叶子向外张开、形态不变、不穿模；
   - 球**下移 3**（`cy0=5`）、球心固定 `x=z=8`；只删 2 片"绕 Y 轴 ±45°、必然穿心"的斜板；
   - **`rosette_age_5_fruiting` 保持原版**（它的球本就在叶片之上，不存在穿模）。
3. **零厚度元素的面类型必须与零厚度轴匹配**（x 零厚度→east/west…），否则**静默不渲染**。
4. `rotation.angle` 只能取 `-45/-22.5/0/22.5/45`。

### 4.2 画法
- **一行一段连续像素** ⇒ 结构上不可能有封闭洞（本会话所有植物贴图都这么做）；
- 🛑 **禁止公式化上色**：`(x+y)%4` 轮转四档色 ⇒ **规则斜向编织纹**（真实事故，见 §六·2）；
- **手工逐格配色** + **"同色连通块修复迭代"**（>3 的 4 连通块，把多余像素换成"四邻都没有的颜色"，**只改色不改形**，直到 ≤3）；
- 苗期 = **孤立 1px 点**（TFC `lentil_0` 5px / `cabbage_0` 3px）；成熟期 = **密而透**（叶团实心连续 + 1~2 个 1px 错位洞）；
- **枯死态** = 整株换**卡其/深褐灰**（不是黑、不是粉、不是亮橙）+ **收获器官留色**；
- **树叶照 TFC**（用户明令"尽可能少自创"）：`transplant.ps1` 移植 TFC 形状 + 本物种色阶；**TFC 树叶是"密布 150~210/256 + 1px 不规则散洞 + 3~5 档极相近同族绿"，枯叶是深褐灰**。

### 4.3 检测器（**只挑候选，永不作为验收**）
- **门框检测**：连续 ≥3 行"恰好两段"且**两段间空档 ≥3 格**在 x 上持续重叠（1~2 格间隙是正常叶隙）；
- **同色 4 连通块 ≤3**（植物类）；**封闭洞**（植物类 = 0，**树叶类要 >0**）；
- 旧工具 `arch-detect / arch2-detect / hole-detect / bridge-detect` 会连带扫描死贴图 ⇒ **先过滤 live**。

### 4.4 "占位贴图"的量化判据（新会话收尾"新物种占位"必跑）
`& .probe/texture-design/r49-tfc-similarity.ps1` ⇒ 剪影 IoU ≥0.90 即疑似占位（1.00 = 逐像素相同）。
