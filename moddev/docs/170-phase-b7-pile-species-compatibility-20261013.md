# B-7：木料堆树种一致性修复

**日期：** 2026-10-13  
**状态：** 代码修复、构建和静态门禁完成；等待实机确认混木拒绝与自动化行为。

## 修复内容

- 木料堆不再只按“是否属于木料标签”判断输入，而是按树种建立稳定身份。
- TFC 和 ArborFirmaCraft 的 34 种木材统一按树种名匹配；同一树种的整木、半木和四分木可以共存。
- 不同树种不能放入同一个木料堆，也不能通过潜行连续放入绕过检查。
- 自动化 `ItemHandler` 插入与鼠标放入使用同一套树种校验。
- 纵向木料柱整理时只在同树种段内向下合并，避免把相邻的不同树种柱段重新压到一起。
- 未知数据包扩展木料不猜测名称后缀，而是按完整物品注册 ID 匹配，降低误合并风险。
- 旧区块读取仍保留；已保存的历史物品会继续载入，整理时不会静默丢弃。
