# K3 面团案板确认加工施工记录（2026-10-21）

## 已完成内容

- `CuttingBoardBlockEntity` 增加按压次数、揉捏次数、持久化读档和状态清零逻辑，继续使用 TFC `InventoryBlockEntity<ItemStackHandler>` 容器接口。
- 增加空手左键按压、普通空手右键揉捏、空手潜行+右键确认、空手潜行+左键取回。
- 面团放置后显示“左键按压面团，右键揉捏面团，潜行+右键确认产物”。无效次数确认显示“面团尚未成型”，不消耗面团和计数。
- 蛋糕面团支持 3 按压 + 3 揉捏生成未烤制蛋糕坯，2 按压 + 1 揉捏生成两份未烤制甜煎饼。
- 普通谷物面团支持 3 按压生成未烤制披萨饼，4 按压 + 2 揉捏生成对应谷物未烤制烤馕。
- 小刀支持蛋糕面团生成生面圈、蛋糕坯切小蛋糕、普通面团小圆面包和零计数面团制面条。
- 增加蛋糕面团、蛋糕坯、甜煎饼、面圈、披萨、面条、六种谷物烤馕和六种谷物小圆面包的物品注册、模型、语言和 TFC 食品数据。
- 增加 Firmalife 搅拌碗配方：六种酵种面团、六种水粗面团和蛋糕面团；原有工作台配方保留。
- 增加 Firmalife 烤炉配方：蛋糕坯、小蛋糕、甜煎饼、烤馕和小圆面包。
- 增加奶油蛋糕和巧克力蛋糕方块，使用 TFC 可放置食品方块实体保存六份切片；奶油容器消耗 100 mB，巧克力糊读取 Firmalife 标签。
- JEI 不再注册旧面团成型和熔化分类，也不再添加旧催化剂；旧注册保留用于存档兼容并隐藏玩家入口。
- 删除旧通用面团配方、旧整蛋糕配方和自定义熔化配方；整派配方改为使用原版面团标签。
- Patchouli 中英文厨房页面改写为搅拌碗 → 案板确认 → 烤炉/装饰流程。
